# Fonts

Both families are self-hosted variable fonts, subset to latin / latin-ext.

- **Archivo** — Omnibus-Type. SIL Open Font License 1.1.
  https://github.com/Omnibus-Type/Archivo
- **JetBrains Mono** — JetBrains. SIL Open Font License 1.1.
  https://github.com/JetBrains/JetBrainsMono

The SIL OFL permits redistribution and web embedding provided the fonts are
not sold on their own and the license accompanies them.
